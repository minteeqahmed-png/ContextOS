# Development baseline

This repository's initial snapshot contains a ContextOS prototype developed before and around the hackathon kickoff, including work from October 23–26, 2026. The repository is being initialized on October 27, 2026. Its first commit date does not mean all included code was written that day.

The initial snapshot includes the local capture/OCR/evidence interface, privacy review, optional Meta provider integration, a working Gemini configuration, and the included evaluation reports. Gemini was the live-tested provider; Meta inference was not demonstrated in those reports.

For any hackathon submission, identify later eligible contributions explicitly and obtain organizer guidance on reuse of this baseline. Do not present this entire initial snapshot as new event-period work. See SUBMISSION_READINESS.md for the known competition requirements and remaining work.
